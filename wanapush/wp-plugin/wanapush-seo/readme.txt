Permet à WanaPush (https://wanatest.com/wanapush) de modifier les meta SEO de ce site directement depuis sa plateforme.

== Description ==

Ce plugin sert de pont entre votre site WordPress et la plateforme WanaPush. Une fois installé et activé, WanaPush peut :

* Modifier le title SEO de chaque page/article
* Modifier la meta description
* Modifier la balise canonical
* Modifier les Open Graph tags (Facebook, LinkedIn)
* Modifier les Twitter Cards
* Modifier la meta robots (index/noindex)

Aucune configuration nécessaire. Le plugin s'efface automatiquement si Yoast SEO, Rank Math ou All in One SEO est détecté (pour éviter les doublons de meta tags).

== Installation ==

1. Télécharger le ZIP depuis votre dashboard WanaPush
2. Aller dans Extensions → Ajouter → Téléverser une extension
3. Choisir le ZIP et cliquer "Installer maintenant"
4. Activer le plugin
